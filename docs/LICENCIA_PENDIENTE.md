# Licencia por acordar

Este repositorio reúne un proyecto académico con cuatro autores. No se agrega automáticamente una licencia abierta al código ni al artículo, ya que eso requiere acuerdo de los titulares.

Antes de publicar, el equipo puede revisar conjuntamente una licencia de software (por ejemplo, MIT, si todos la aprueban) y una licencia para el manuscrito/figuras si resulta pertinente y compatible con la política de la revista. La licencia ODbL de OpenStreetMap se mantiene independientemente.
